## 1. 平台业务全貌

测试管理平台是公司级测试工作统一管理平台，承载**十几个测试团队、几十个业务系统**的测试资产管理与测试执行度量。

```
                    ┌────────────────────────────┐
                    │        测试管理平台          │
                    └────────────────────────────┘
                                  │
   ┌──────────────┬──────────────┼──────────────┬──────────────┐
   v              v              v              v              v
 测试资产       组织归属        版本计划        执行方式        统计报表
 (阶段一)       (阶段二)        (阶段三)        (阶段四)        (阶段五)
 项目/用例      团队/工作台     迭代/一键执行   手动/定时/流水线  三级报表体系
```

**核心业务主线**（也是本文档集的组织方式）：

```
建项目 → 录用例 →（归属团队）→ 建版本计划 → 执行测试（区分执行方式）→ 看报表复盘
```

## 2. 用户角色

| 角色 | 在平台做什么 |
|---|---|
| 测试总监 / 测管管理者 | 看全平台报表、团队横向对比 |
| 测试经理 | 管理团队项目归属、巡检团队项目质量、下钻定位问题 |
| 项目测试负责人 | 维护项目与用例、创建版本计划、执行测试、分析失败用例 |

> 本期不含用户登录与权限，所有角色可见全部数据；角色区分仅用于需求描述。

## 4. 全局业务规则（跨阶段通用）

| 规则 | 内容 |
|---|---|
| 数据归属 | 所有业务数据（用例、计划、执行、统计）都归属到唯一项目 |
| 级联删除 | 删除项目 = 同时清理该项目用例、版本计划、执行记录、统计数据（删除前二次确认） |
| 值域管理 | 枚举类字段（测试团队、执行方式）中，执行方式已字典化，测试团队暂为固定四值 |
| 时间口径 | 业务操作时间取操作时刻；版本计划时间由用户指定（可为过去/未来）；报表统计为 T+1 |
| 时间范围 | 报表类查询时间跨度上限 366 天 |

## 5. 全局范围边界（截至本版）

- 不做用户登录、权限、审批流；
- 不做测试环境管理、测试数据构造、缺陷管理（缺陷实体未建设）；
- 一键执行为**模拟执行**（随机分配成功/失败），非真实对接执行引擎——对接自动化流水线属于后续规划；
- 报表不做实时（T+1 跑批口径）。
